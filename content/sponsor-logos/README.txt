PAST SPONSOR LOGO FILES
=======================

The sponsor list itself is controlled in site-config.txt using [SPONSOR] sections.

Current fixed local logo files:
02-microsoft-logo.svg
06-bdo-logo.svg

AWS and Google Cloud currently use public brand artwork URLs.
Elastic and Couchbase currently use the exact SVG assets from the public HackerRivals repository.

If you later want every logo stored locally, download the approved sponsor artwork into this folder and change image= in site-config.txt to the new local filename.

BDO vector source: https://commons.wikimedia.org/wiki/File:BDO_Deutsche_Warentreuhand_Logo.svg
